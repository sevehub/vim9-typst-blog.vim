1. Intro                                                   *typst-blog-intro*

vim9-typst-blog.vim manages the drafting workflow for a Typst-powered
static blog. Drafts are plain Markdown files in any directory. On publish,
a draft is converted to a Typst post: the standard `article` preamble is
added and the body is converted (pandoc by default) and written into the
blog repository. Published posts can be cross-linked Zettelkasten-style.

Two locations are configured: the draft directory (|g:typst_blog_draft_dir|)
and the blog repository (|g:typst_blog_root|). They may be the same
repository or entirely separate.

The plugin never generates or edits `website.typ`; it is only imported by
generated preambles. The build is never run unless |:BlogCompile| is called.

==============================================================================
2. Setup                                                   *typst-blog-setup*

Install with a Vim9 plugin manager, or manually: >

    git clone https://github.com/sevehub/vim9-typst-blog.vim \
        ~/.vim/pack/bundle/start/vim9-typst-blog.vim
<
Set the two locations in the vimrc, for example: >

    g:typst_blog_root      = 'C:/work/blog'
    g:typst_blog_draft_dir = 'C:/notes/blog-drafts'
<
Requires Vim 9.0+ with |+vim9script|. Conversion requires `pandoc` on the
PATH (see |g:typst_blog_convert_cmd|); without it the body is copied
unconverted.

==============================================================================
3. Drafts                                                *typst-blog-drafts*

A draft is a Markdown file with optional YAML front matter: >

    ---
    title: My Post
    subtitle: A short line
    keywords: typst, vim
    author: SEVETECH
    ---

    Body in Markdown.
<
Recognised keys: `title`, `subtitle`, `keywords`, `author`. When `title` is
missing, a first `# Heading` is used; when both are missing, the file name
is used. A first heading is removed from the body, since the preamble adds
the title heading itself. Missing `author` falls back to |g:typst_blog_author|.

==============================================================================
4. Commands                                              *typst-blog-commands*

:BlogNew {title}                                                  *:BlogNew*
    Create `{draft_dir}/{slug}.md` with front matter (title filled in,
    subtitle and keywords blank), write it, and start insert mode on the
    subtitle line. The directory is created when missing.

:BlogPublish                                                  *:BlogPublish*
    Convert the current draft into `{root}/{publish_dir}/{slug}.typ`:
    preamble (title, subtitle, author, today's date, keywords), a title
    heading, and the converted body. The new file is opened. The draft is
    left unchanged. Asks before overwriting an existing post. Only works
    for files inside |g:typst_blog_draft_dir|.

:BlogList                                                        *:BlogList*
    Fuzzy-pick and open a draft. Delegates to fdminifuzzy.vim when
    available (see |typst-blog-integrations|), otherwise uses a built-in
    matchfuzzy() picker.

:BlogListAll                                                  *:BlogListAll*
    Same as |:BlogList|, searching drafts and published posts together.

:BlogOpenDrafts / :BlogOpenPublished          *:BlogOpenDrafts* *:BlogOpenPublished*
    Open the picker scoped to drafts or to published posts.

:BlogLink                                                        *:BlogLink*
    Fuzzy-pick a published post and insert
    `#link("/posts/foo.typ")[Title]` below the cursor, using a repo-root
    relative path and the title parsed from that post's preamble. Drafts
    are not linkable.

:BlogBacklinks                                              *:BlogBacklinks*
    Fill the quickfix list with every published post that links to the
    current one and open it.

:BlogCompile                                                  *:BlogCompile*
    Run the typstpowershell compile command when loaded, else `make` in
    |g:typst_blog_root|, else `typst compile` on the current `.typ` file.
    See |g:typst_blog_compile_cmd|.

==============================================================================
5. Configuration                                            *typst-blog-config*

                                                        *g:typst_blog_root*
g:typst_blog_root ~
    Blog repository root. Published posts are written below it.
    Default: |getcwd()| at plugin-load time.

                                                    *g:typst_blog_draft_dir*
g:typst_blog_draft_dir ~
    Draft directory (Markdown). Relative to |g:typst_blog_root| unless
    absolute. Default: `"DRAFT"`.

                                                  *g:typst_blog_publish_dir*
g:typst_blog_publish_dir ~
    Directory for published Typst posts. Relative to |g:typst_blog_root|
    unless absolute. Default: `"posts"`.

                                                  *g:typst_blog_import_path*
g:typst_blog_import_path ~
    Path used in the generated `#import "..."` line.
    Default: `"/libs/website.typ"`.

                                                       *g:typst_blog_author*
g:typst_blog_author ~
    Author used when a draft has none. Default: `"SEVETECH"`.

                                                    *g:typst_blog_draft_ext*
g:typst_blog_draft_ext ~
    Draft file extension. Default: `".md"`.

                                                           *g:typst_blog_ext*
g:typst_blog_ext ~
    Published post extension. Default: `".typ"`.

                                                *g:typst_blog_convert_cmd*
g:typst_blog_convert_cmd ~
    Command that reads Markdown on stdin and writes Typst on stdout.
    Default: `"pandoc -f markdown -t typst"`. An empty string disables
    conversion and the body is copied unchanged.

                                                      *g:typst_blog_picker*
g:typst_blog_picker ~
    Funcref(list<string>): string used by |:BlogLink| (and as a fallback
    elsewhere) to reduce candidate files to one path. Default: `''`, the
    built-in matchfuzzy()+inputlist() picker.

==============================================================================
6. Integrations                                       *typst-blog-integrations*

fdminifuzzy.vim ~
    https://github.com/sevehub/fdminifuzzy.vim

    |g:typst_blog_fuzzy_cmd| (default `"FdMiniFuzzy"`) names the Ex command
    used by the list commands to open a directory-scoped picker. When the
    command does not exist, the built-in picker is used.

    |:BlogLink| needs the chosen path returned, so it always uses
    |g:typst_blog_picker|. A synchronous picker can be wired in: >

    g:typst_blog_picker = (files) => fdminifuzzy#PickOne(files)
<
typstpowershell ~
    https://github.com/sevehub/typstpowershell

    |g:typst_blog_compile_cmd| (default `"TypstCompile"`) names the Ex
    command |:BlogCompile| delegates to when it exists.

==============================================================================
7. Mappings                                              *typst-blog-mappings*

Buffer-local mappings are defined in `.typ` buffers and in Markdown files
located inside |g:typst_blog_draft_dir|, rooted at |g:typst_blog_map_prefix|
(default `<localleader>b`): >

    <prefix>n   :BlogNew (command line, for the title)
    <prefix>p   :BlogPublish
    <prefix>l   :BlogList
    <prefix>a   :BlogListAll
    <prefix>i   :BlogLink
    <prefix>b   :BlogBacklinks
    <prefix>c   :BlogCompile
<
Set `g:typst_blog_no_mappings = v:true` before the plugin loads to disable
them.
